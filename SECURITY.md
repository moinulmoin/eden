# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/moinulmoin/eden/security/advisories/new) in this repository's **Security** tab. Do not disclose vulnerabilities or secrets in public issues.

## Supported versions

Security fixes are provided only for the latest minor release line. Use its latest patch version.

## Scope

This policy covers the Eden CLI, Cloudflare runtime and World packages, and release pipeline.

Only test deployments and accounts you own or have explicit permission to test. Do not test against other people's deployments.
